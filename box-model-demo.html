CSS na prática

O box model

Todo elemento HTML é uma caixa. Os exemplos abaixo mostram as quatro camadas dessa caixa: conteúdo, espaçamento interno, borda e espaçamento externo.

O que é

O box model é o modelo que o navegador usa para calcular o tamanho e o espaço de cada elemento. Ele tem quatro camadas, de dentro para fora:

  • content — o conteúdo em si: texto, imagem etc.
  • padding — o espaço entre o conteúdo e a borda.
  • border — a borda ao redor do padding.
  • margin — o espaço entre a borda e os elementos vizinhos.
.caixa {
  width: 160px;       /* content */
  padding: 20px;       /* padding  */
  border: 4px solid;   /* border   */
  margin: 20px;        /* margin   */
}

Exemplos interativos

Use os controles para mudar os valores e ver a caixa reagir na hora.

content 
.caixa {
  padding: 20px;
  border: 4px solid #e10000;
  margin: 20px;
}

content-box × border-box

Por padrão, width define só o tamanho do content; padding e borda são somados por fora, e a caixa fica maior do que o width definido. Com box-sizing: border-box, o padding e a borda passam a ser descontados de dentro do width, e a caixa fica exatamente do tamanho definido.

  • content-box (padrão)

    200px de width
    .caixa {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 4px solid;
}
/* largura final: 248px */

  • border-box

    200px de width
    .caixa {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 4px solid;
}
/* largura final: 200px */

Boas práticas

  • É comum começar o CSS com *, *::before, *::after { box-sizing: border-box; }, para que todo elemento siga a mesma regra de tamanho.
  • margin entre blocos pode somar de forma diferente do esperado (margin collapsing); vale testar quando o espaçamento parecer maior do que o definido.
  • Use o inspecionar elemento do navegador (F12) para ver as quatro camadas de qualquer elemento da página.

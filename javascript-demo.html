JavaScript na prática

JavaScript básico

Enquanto o CSS cuida da aparência, o JavaScript dá comportamento à página: ele reage a cliques, muda o conteúdo e toma decisões. Teste cada exemplo abaixo.

O que é

JavaScript é a linguagem de programação que roda no navegador. Um script "escuta" eventos — como um clique — e, quando o evento acontece, executa um código que pode ler e alterar o próprio HTML da página.

elemento.addEventListener('click', function () {
  // código que roda quando o elemento é clicado
});

Exemplos

  • 1. Trocar o texto de um elemento

    Clique no botão abaixo

    const saudacao = document.getElementById('saudacao');
const botao = document.getElementById('botaoSaudacao');

botao.addEventListener('click', () => {
  saudacao.textContent = 'Olá! O JavaScript mudou este texto.';
});

  • 2. Contador com uma variável

  • 3. Mostrar e esconder (toggle de classe)

    Este parágrafo estava escondido com a classe .oculto.

    const detalhe = document.getElementById('detalhe');

botaoAlternar.addEventListener('click', () => {
  detalhe.classList.toggle('oculto');
});

  • 4. Decisão com if

    const idade = Number(campoIdade.value);

if (idade >= 18) {
  resultado.textContent = 'Maior de idade';
} else {
  resultado.textContent = 'Menor de idade';

  • 5. Função que escolhe um item de um array

    const cores = ['#e10000', '#ffd400', '#f8bd6b', '#808080'];

function sortearCor(lista) {
  const indice = Math.floor(Math.random() * lista.length);
  return lista[indice];
}

amostra.style.background = sortearCor(cores);

Boas práticas

  • Use const para valores que não vão mudar e let para os que mudam. Evite var.
  • Separe o JavaScript do HTML sempre que possível, em um arquivo .js próprio, à medida que o código cresce.
  • Abra o console do navegador (F12 → Console) para ver mensagens de erro e testar trechos de código.

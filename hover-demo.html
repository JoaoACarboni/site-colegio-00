CSS na prática

A pseudoclasse :hover

Passe o mouse sobre cada exemplo abaixo para ver o efeito acontecer. No celular, toque no elemento.

O que é

:hover é uma pseudoclasse: ela aplica um estilo a um elemento somente enquanto o cursor do mouse está sobre ele. Assim que o mouse sai, o elemento volta ao estilo normal.

seletor:hover {
  propriedade: valor;
}

É muito usada para dar uma resposta visual antes do clique: botões, links, cartões e menus.

Exemplos

  • 1. Botão muda de cor

    .botao {
  background: #e10000;
  transition: background-color .2s;
}

.botao:hover {
  background: #b30000;
}

  • 2. Link ganha sublinhado

    Este é um link de exemplo 
    a {
  text-decoration: none;
}

a:hover {
  text-decoration: underline;
}

  • 3. Cartão "levanta" e ganha sombra

    Curso técnico Passe o mouse aqui 
    .cartao {
  transform: translateY(0);
  box-shadow: 0 2px 6px rgba(0,0,0,.15);
  transition: transform .2s, box-shadow .2s;
}

.cartao:hover {
  transform: translateY(-8px);
  box-shadow: 0 14px 24px rgba(0,0,0,.18);
}

  • 4. Legenda aparece sobre a imagem

    Legenda que aparece no hover
    .imagem .legenda {
  opacity: 0;
  transition: opacity .25s;
}

.imagem:hover .legenda {
  opacity: 1;
}

  • 5. Item de menu com barra lateral

    Início Cursos Contato 
    .menu a {
  border-left: 4px solid transparent;
}

.menu a:hover {
  border-left-color: #ffd400;
  background: #fff8e3;
}

  • 6. Ícone aumenta de tamanho

    ★ 
    .icone {
  display: inline-block;
  transition: transform .2s;
}

.icone:hover {
  transform: scale(1.4) rotate(-10deg);
}

Boas práticas

  • Use transition para o efeito acontecer suavemente, em vez de trocar o estilo de uma vez.
  • :hover não funciona bem em celulares, porque não há cursor. Para quem usa toque, pense também em :focus e em um estado "ativo" por toque.
  • Evite depender só do hover para mostrar uma informação importante, porque ela fica escondida até o usuário passar o mouse.

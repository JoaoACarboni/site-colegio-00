Começar pela etapa 1

Etapas de desenvolvimento

  1. 1

    HTML: a estrutura e o conteúdo

    Primeiro escrevemos só o HTML. Ele define o que existe na página: o cabeçalho, o menu, os nove cursos, os dados de contato e o rodapé. Sem CSS, tudo aparece com o visual padrão do navegador, e é isso que mostra o papel do HTML.

    • Títulos <h1> a <h3> organizam a leitura.
    • Listas <ul> guardam os cursos.
    • Tags como <header>, <main> e <footer> dão sentido a cada parte.
    <section id="cursos">
  <h2>Cursos técnicos</h2>
  <ul>
    <li>
      <h3>Desenvolvimento de Sistemas</h3>
      <p>Programação, banco de dados...</p>
    </li>
  </ul>
</section>
    Ver a página só com HTML
  2. 2

    CSS: cores, tipografia e layout

    Depois ligamos o CSS ao mesmo HTML, sem mudar o conteúdo. Ele aplica a paleta da logo, escolhe as fontes, organiza as seções em colunas e adapta a página para o celular.

    • Cores da logo guardadas em variáveis: vermelho, amarelo, pêssego e cinza.
    • Layout com grid e flex.
    • Regras @media para telas pequenas.
    :root {
  --vermelho: #e10000;
  --amarelo: #ffd400;
  --pessego: #f8bd6b;
  --cinza: #808080;
}

.curso {
  border-left: 8px solid var(--vermelho);
}
    Ver a página com CSS
  3. 3

    CSS: a pseudoclasse :hover

    Com a estrutura e o visual prontos, vale parar numa funcionalidade do CSS por vez. A primeira é o :hover: ele aplica um estilo só enquanto o mouse está sobre o elemento, e some assim que o mouse sai.

    • Botões, links e cartões que reagem ao mouse.
    • Uso de transition para o efeito ficar suave.
    • O que muda no toque, em telas de celular.
    .botao {
  background: #e10000;
  transition: background-color .2s;
}

.botao:hover {
  background: #b30000;
}
    Ver a página do :hover
  4. 4

    CSS: o box model

    Outra base do CSS é o box model: todo elemento é uma caixa com quatro camadas — content, padding, border e margin. Entender essas camadas explica por que um elemento ocupa mais espaço do que o width definido, e como corrigir isso.

    • As quatro camadas, de dentro para fora.
    • Controles para testar padding, border e margin ao vivo.
    • A diferença entre content-box e border-box.
    .caixa {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 4px solid;
  margin: 20px;
}
    Ver a página do box model
  5. 5

    JavaScript básico

    Por fim, o JavaScript dá comportamento à página: ele reage a cliques, muda o conteúdo na hora e toma decisões, coisas que HTML e CSS sozinhos não fazem.

    • Eventos, como click, e funções.
    • Variáveis com let e const.
    • Manipulação do DOM: ler e trocar o conteúdo da página.
    const botao = document.getElementById('botao');

botao.addEventListener('click', () => {
  botao.textContent = 'Clicado!';
});
